# Databibliotek nygeneration.se
Detta repo innehåller data-filer som används på våran hemsida nygeneration.se. 

## Att länka till data-filer
Alla filer publiceras på en webserver med `github pages`. Du kommer åt filerna med hjälp av länken nedan där du byter ut `<path to file>` mot filens sökväg. 

`https://nygenerati0n.github.io/webpage-data/<path to file>`

### Exempel
---

Om du ska hämta filen `schools.json` så blir länken:

`https://nygenerati0n.github.io/webpage-data/schools.json`
